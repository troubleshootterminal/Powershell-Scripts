# PowerShell Scripts

A growing collection of PowerShell scripts for system administration, infrastructure management, troubleshooting, automation, and reporting.

This repository serves as a central location for practical PowerShell tools developed to simplify day-to-day IT operations and improve efficiency across Windows environments.

---

## Features

- Infrastructure automation
- System diagnostics
- Network troubleshooting
- Server administration
- Endpoint management
- Reporting and auditing
- Microsoft 365 administration
- Azure administration
- Security and compliance checks
- IT support utilities

---

## Requirements

- Windows PowerShell 5.1 or later
- PowerShell 7+ (recommended)
- Appropriate administrative permissions
- Access to target systems where applicable

---

## Getting Started

Clone the repository:

```powershell
git clone https://github.com/troubleshootterminal/Powershell-Scripts.git
cd Powershell-Scripts
```

Run a script:

```powershell
.\ScriptName.ps1
```

Example:

```powershell
.\Network Summary in Seconds.ps1
```
